# dag

| Category | Scope |
|----------|-------|
| Framework | pipeline |

## Configuration

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `message` | string |  | Message text to log or process. |

## Example

```yaml
processor:
  - dag:
      message: "message"
```
